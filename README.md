# Same Pipeline, Different Answers: code and data

Code, per-run results and per-case scores for the paper *Same Pipeline, Different Answers: Seed, Threshold
and Input Effects in Transfer Learning for Breast Ultrasound Classification*
(H. Uddin, M. T. Khan, C. Biswas, M. H. Mobarok; Southeast University, Dhaka). Everything needed to check
or recompute the paper's numbers is here; model weights are not distributed. BUSI itself is not included
(get it from its authors, Al-Dhabyani et al., 2020).

## Layout

| Path | What it is |
|---|---|
| `BreastCancerConf.ipynb` | Original training notebook (run A). Cell 2 builds the preprocessed dataset: lesion crop from the mask, extra-lesion pixels zeroed, padded to square, resized to 224. Later cells are the earlier Grad-CAM++, BUS-BRA and ensemble work, which the paper does not use. |
| `experiments/MultiSeed_BUSI.ipynb` | **Main reproducible experiment.** 5 backbones × {PF, FT} × 5 seeds, plus a same-seed repeat and a shape-only control. Generated by `experiments/build_multiseed_notebook.py`. |
| `experiments/README.md` | How the multi-seed run was executed and how to resume it. |
| `experiments/A1_scaling_check.md` | Diagnostic showing that run A's VGG16-PF test result matches unscaled test input. |
| `experiments/FollowUp_BUSI.ipynb`, `experiments/followup_cells.py` | Follow-up of 34 runs: native `preprocess_input` for VGG16/ResNet50 (PF, FT, seeds 0–4), silhouette built from the expert mask, whole image without mask or crop (DenseNet121-PF, VGG16-PF, seeds 0–2), and VGG16-PF seed 0 twice with op determinism. |
| `experiments/native3_cells.py` | Second follow-up of 30 runs: native `preprocess_input` for Xception, InceptionV3 and DenseNet121 (PF, FT, seeds 0–4). |
| `experiments/multiseed_results/` | Outputs of all 122 runs (58 main/control runs plus 64 follow-up runs) (`runs/<tag>/result.json`, `history.json`, `scores.npz`), the partition (`split.csv`), environment logs, the A1 diagnostic, the summary printed in Colab (`summary_colab.csv`) and the analysis outputs (`summary_all_runs.csv`, `multiseed_stats.json`, `numbers_multiseed.txt`). |
| `analysis/multiseed_analysis.py` | Computes every multi-seed number in the paper: mean/SD per configuration, same-seed repeat differences, shape-only control, validation-tuned thresholds, PF-vs-FT McNemar with Holm correction, native-vs-[0,1] comparison, input controls and the op-determinism check. NumPy only. |
| `analysis/calibration_analysis.py` | Brier score and expected calibration error (ten equal-width bins) of every run on the test set, from the per-case scores; writes `calibration_runs.csv` and `calibration_numbers.txt`. NumPy only. |
| `analysis/dedup_sensitivity.py` | Duplicate-leakage check: 64-bit difference hash of every original BUSI image (needs the BUSI images), flags test images within four bits of a training or validation image and re-scores every run on the remaining test images; writes `dedup_pairs.csv`, `dedup_test_leaked.txt`, `dedup_runs.csv` and `dedup_numbers.txt`. |
| `analysis/make_multiseed_figs.py` | Generates `fig_seeds.tex` and `fig_auc_err.tex` (pgfplots) from `summary_all_runs.csv`. |
| `analysis/three_runs_analysis.py`, `three_runs.json` | Analysis of the three earlier runs (A, B, C). |
| `analysis/make_pgf_figs.py` | Generates the pgfplots figure sources from `three_runs.json`. |
| `validation_threshold_rescoring.py` | Re-thresholds saved run-B/C models at the validation Youden cut-point. |
| `drive_results/` | Snapshot of the earlier runs' results from Google Drive. No model weights; see its README and `MODEL_CHECKSUMS.txt`. |
| `requirements.txt` | Package versions of the multi-seed run. |

## Reproducing the multi-seed experiment

1. Get BUSI (Al-Dhabyani et al., 2020). Run cell 2 of `BreastCancerConf.ipynb` to build
   `processed_images/{benign,malignant}` (437 benign, 210 malignant; normal images excluded).
2. Open `experiments/MultiSeed_BUSI.ipynb` in Colab with a T4 GPU and set `DRIVE_BASE` in cell 1.
   Run cells 1–4, then cell 5 (A1 diagnostic, optional), cell 6 (all training runs) and cell 7 (summary).
   - The split is rebuilt with the paper's rule: within each class, a sorted file list shuffled with
     `random.seed(42)`, then cut 70/15/15. This gives 452/97/98 images (test: 66 benign, 32 malignant). The split is saved as `split.csv`.
   - Each run sets `tf.keras.utils.set_random_seed(seed)`. GPU kernels are not deterministic, so the
     same seed does not give identical weights. The `repeat_*` runs measure this.
   - Cell 6 skips runs that already have a `result.json`, so it can be restarted after a disconnect.
3. Copy `multiseed_v1/runs` and run (the outputs already in the repository are produced by exactly these commands):

   ```bash
   python3 analysis/multiseed_analysis.py experiments/multiseed_results/runs experiments/multiseed_results
   python3 analysis/calibration_analysis.py experiments/multiseed_results
   python3 analysis/dedup_sensitivity.py /path/to/Dataset_BUSI_with_GT experiments/multiseed_results 4
   python3 analysis/make_multiseed_figs.py experiments/multiseed_results figures_src
   ```

   Compile each figure source with `tectonic` or `pdflatex` and place the PDFs next to `main.tex`.

## Notes for reviewers

- The test split is used only for the final evaluation. The checkpoint (maximum validation AUROC) and
  the decision threshold (Youden's J on validation) are both chosen on the validation split.
- `scores.npz` stores per-case validation and test scores with file names, so any metric can be recomputed
  without retraining.
- Training code for the earlier runs B and C was not kept; that is why the multi-seed experiment was run
  from one documented notebook, and the paper uses runs A–C only as motivation.
- Model weights are not included (checkpoints were deleted after evaluation); every reported number can be
  recomputed from the saved per-case scores.
